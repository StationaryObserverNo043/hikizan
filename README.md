🐱 hikizan

予算を決める → 使う → 残りを見る。

あといくら使えるかが分かる、シンプルな予算管理アプリ『ヒキザン』。

---

🏠 このアプリについて

レシートを読み取り、毎月の家計をシンプルに記録・管理するためのWebアプリです。

「家計簿をつけたい。でも、入力が面倒。」

そんなところから、自分たちの家庭で使うために作り始めました。

レシートをスマートフォンのカメラで読み取り、支出を記録。

今月の予算に対して、

«「あといくら使える？」»

をすぐ確認できることを目指しています。

---

🔒 大切にしていること

このアプリでは、家計データをできるだけ外部に送信せず、利用している端末内で管理することを基本方針としています。

«手軽に、自分のデータを、自分の手元で管理する。»

そんな考えから設計しています。

---

✨ 主な機能

- 📷 レシートの読み取り
- 🧾 支出の自動入力
- 💰 月間予算の設定
- 📊 今月の支出額・残り予算の確認
- 🗂️ 支出データの管理
- 💾 データのバックアップ・エクスポート
- 📱 スマートフォンでの利用
- 🌐 PWAとしてホーム画面に追加して利用

---

🛠️ 技術

HTML / CSS / JavaScriptを中心に構成しています。

可能な限り外部サーバーに依存せず、ブラウザ上で動作する構成を目指しています。
